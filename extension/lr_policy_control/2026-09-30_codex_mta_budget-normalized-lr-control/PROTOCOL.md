## Question and causal boundary

Does the paired CIFAR-10 top-k-minus-dense best-validation-accuracy mean sign change from positive at three epochs to negative at thirty epochs when the original constant AdamW learning rate is replaced by a budget-normalized linear decay? The intervention is the optimizer learning-rate schedule. It does not isolate attention sparsity as a causal mechanism, and it does not establish cross-task or large-model behavior.

The targeted eight-paper prior-art note and one-sentence falsifiable distinction are in `MD/01_literature/2026-09-30_lr_policy_control/PRIOR_ART_AND_DIFFERENCE.md`. Li, Yumer and Ramanan (ICLR 2020) and the pinned author `linearlr.py` at commit `1baf88d2d065526d80bf9940321b6c9e1db3e07d` (local SHA256 `FD30378A7954BF2BC08268B886F3658B3876C927C551E7BFDDC412DCC207F738`) define `eta_t=eta_0(1-t/T)`; at short budgets they recommend iteration-based stepping. This is borrowed prior art. The prior fixed-rate matched-control source is `experiments/2026-09-28_codex_mta_matched-bottomk-policy/runtime_cohorts/post_reboot_001/`, with 50 completed 30-epoch cells. It supplies the three required methods' 30-epoch traces for a current-runtime fixed-rate reference only if all thirty rows, producer completion markers, source, data, split, initialization and runtime bindings pass the separate comparator-admission checker. Fixed-rate prefixes of those uninterrupted traces are the same training path through E epochs because the sole `max_epochs` dependency is the loop bound and patience is zero; GPU execution is not promised bitwise deterministic. This is a within-path reference, not a fresh independent replicate. The older torch 2.11 ladder is historical context and is never pooled with the new torch 2.13 population.

## Frozen cells and numerical method

- Dataset: verified official CIFAR-10 training archive SHA256 `6D958BE074577803D12ECDEFD02955F39262C83C16FE9348329D7FE0B5C001CE`, 50,000 training-pool images only. Per seed, use the original deterministic 40,000/10,000 training/validation split. The official test member is neither extracted nor unpickled.
- Methods: `softmax`, `topk_softmax_0125`, `topk_softmax_025`. Seeds: integers 0 through 9, paired by method and budget. Budgets: exactly 3, 6, 9, 12, 18, 24, 30 epochs. Exactly 3 x 10 x 7 = 210 new decay cells; each is trained from the seed's original initialization. No selection of a method, seed, budget, or checkpoint after observing outcomes.
- Architecture/data semantics: original `benchmark_r1.py` numerical core, compact tier (two blocks, width 64, four heads), patch 4, 65 tokens including CLS, dropout 0.1, batch 256, train fraction 0.8, validation fraction 0.2. AdamW base learning rate 0.001, weight decay 0.0001, gradient clipping 5, patience 0. No warmup, ratio retuning, alternate decay or extra dataset.
- For a budget E, let U=157 be the measured/asserted number of minibatches in each 40,000-example epoch at batch 256, and T=E*U. Just before optimizer update t, with t=0,...,T-1, set `lr_t = 0.001*(1-t/T)`. Record the first and last LR for every epoch, a byte hash of all T packed float64 applied LRs, and require exactly T updates. The last applied LR is 0.001/T; zero occurs just after the budget, not as an extra update. This follows the pinned author implementation's progress-normalized iteration formula. AdamW's decoupled weight-decay step is multiplied by the current LR; the intervention therefore changes effective weight decay per update together with the LR, as any such scheduler does. It is a policy comparison, not an isolated gradient-step-size mechanism. A changed minibatch count invalidates the cell rather than silently changing T.
- Preserve original RNG call order and parameter initialization; the only numerical intervention is the AdamW LR schedule (including its linked decoupled decay magnitude). The new worker must assert initial parameter SHA equality with the corresponding frozen fixed-rate method/seed row before training, split-index hashes (including smoke seeds), train-array hashes, dataset archive identity, precision `high`, source SHA and the full 20-field runtime identity. The original source module contains a test decoder, but the worker must not call it, decode an official-test member or read an official-test label; its reachable test/download/cache functions are replaced by raising stubs and checked after execution.

Secondary: terminal validation accuracy, accuracy-selected and terminal macro-F1, selected epoch, full epoch accuracy/loss/F1/attention traces, LR trace, update count, wall time and peak allocated memory. Never choose a checkpoint by F1 or by official test score.

For each fraction and each E, report ten paired top-k-minus-dense accuracy differences, their mean, sample SD, and nominal two-sided 95% Student-t interval (df 9), explicitly descriptive and unadjusted. All sign tests use exact integer correct-count differences on the 10,000-image validation sets; their sum is zero exactly when the paired mean is zero. The *finite answer to RB-01* is the sign pair at E=3 and E=30 for each fraction: `persists` only when the decay-policy count sum is >0 at 3 and <0 at 30; `fails` otherwise (including exact zero).
